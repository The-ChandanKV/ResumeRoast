# Data Analyst Intern

Example Transit Lab seeks a student to prepare data and communicate recurring ridership trends to an operations team.

## Required

- Currently enrolled in statistics, analytics, or a related field.
- SQL joins and aggregations, plus Excel pivot tables.
- Clean datasets and check missing values.
- Build dashboards in Power BI or Tableau.
- Explain findings and recommend a next step for a nontechnical audience.

## Preferred

- Python with pandas and basic A/B testing.
