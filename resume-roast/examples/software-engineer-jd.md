# Software Engineer Fresher

Example Product Studio seeks an entry-level engineer to build and test backend features. Coursework and personal projects qualify as experience.

## Required

- Completed or in-progress degree in computer science or a related field.
- Python, SQL, and Git.
- Build or maintain REST APIs and write unit tests.
- Explain basic data structures and collaborate with teammates through code review.
- Familiarity with CI pipelines.

## Preferred

- Flask or a comparable Python web framework.
- Docker and a cloud deployment project.
